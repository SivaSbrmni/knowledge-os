# UI/UX Standards

All user-facing interface work on Knowledge OS must follow the standards in:

**`.cursor/rules/ui-ux-standards.mdc`**

That rule is embedded for agents: premium craft, empty/loading/error states, no native alerts, trust/citation visibility, and accessible keyboard navigation.

The reference implementation lives in `web/` (`index.html`, `css/app.css`, `js/app.js`).
